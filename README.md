# wmzhang02.github.io

Personal homepage of Weiming Zhang: https://wmzhang02.github.io/

A plain static site with no build step.

- `index.html` — all page content
- `assets/css/style.css` — all styles (colors and fonts are CSS variables at the top)
- `images/` — avatar and favicons

Preview locally with `python3 -m http.server` and open http://localhost:8000.
